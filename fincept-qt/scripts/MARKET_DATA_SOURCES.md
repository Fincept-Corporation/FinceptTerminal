# Market Data Sources

> Real-time and historical financial market data providers

## Overview

Access comprehensive market data from leading financial data providers covering equities, options, crypto, commodities, and forex. Sources provide real-time quotes, historical prices, fundamentals, and market sentiment.

## API Key Setup

```bash
# Required for premium features
export ALPHA_VANTAGE_API_KEY="your_key_here"     # Get from: https://www.alphavantage.co/support/#api-key
export FMP_API_KEY="your_key_here"               # Get from: https://financialmodelingprep.com/
export TRADING_ECONOMICS_KEY="your_key_here"     # Get from: https://tradingeconomics.com/api/
```

## Usage

Every connector is a standalone CLI: `python <script> <command> [args...]` prints JSON on stdout
(`{"error": "..."}` on failure). The authoritative list of connectors, commands, argument hints and
API-key requirements is `resources/data_connectors.json` (generated by
`.github/scripts/gen_data_connectors.py`; browsable in Data Sources > CATALOG). Keys are stored in
Settings > Credentials and injected as environment variables.

```bash
python yfinance_data.py quote AAPL
python alphavantage_data.py quote AAPL
python nasdaq_data.py market_overview
python fmp_data.py equity_quote AAPL
```
