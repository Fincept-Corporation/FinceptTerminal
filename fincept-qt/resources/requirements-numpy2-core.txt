# ESSENTIALS — the subset of requirements-numpy2.txt a new user installs on
# first run: yfinance (the market-data source behind the dashboard, Markets,
# Watchlist and Equity Research) plus two small helpers. Nothing else.
#
# PythonSetupManager installs this straight into venv-numpy2 on first run
# (`uv pip install -r <this> -c requirements-numpy2.txt` — no lock compile),
# so a new user reaches the terminal in about a minute. The constraint file
# makes every version chosen here one the full set pins too, so a later full
# install (Settings → Python Env, or on demand) has nothing to replace.
# When the full set IS requested, the same file is installed first from the
# full lock (`-c <lock>`) so the terminal can open before the rest arrives.
#
# Everything else — news extras (gnews, feedparser), AI, machine learning,
# quant and backtesting libraries, and the whole NumPy 1.x trading
# environment — is optional and arrives with the full set. Scripts that need
# it either fall back (Equity Research news → yfinance feed) or report the
# missing library, which offers the full install. (News sentiment, entities,
# geolocation and translation run in C++ and need no Python at all.)
#
# RULES
#   * Every line MUST also appear in requirements-numpy2.txt with the SAME
#     specifier — the full set and its lock must be able to satisfy it.
#   * Keep it SMALL. This list is what stands between a new user and the
#     terminal; first-run time is measured against it.
#   * Transitive dependencies (pytz, tzdata, dateutil, idna, urllib3, …) are
#     pinned through the constraint file / lock automatically — list only what
#     the scripts import directly.

# numpy/pandas — every analytics script, and yfinance's own data frames
