## Über

**Fincept Terminal** ist ein natives C++20-Desktop-Terminal für Finanzresearch — Qt6-Oberfläche, eingebettete Python-3.11-Analytik, eine einzige Binärdatei, kein Electron.

Es erscheint in **zwei Editionen auf einem gemeinsamen Datenkern**:

| | **Open Source** — dieses Repo | **Enterprise** — [fincept.in/enterprise](https://fincept.in/enterprise) |
|---|---|---|
| **Gedacht für** | Lernen, private Nutzung, akademische Forschung | Fonds, Family Offices, Research-Desks |
| **Preis** | Kostenlos · AGPL-3.0 | Ab **99 $**/Nutzer/Monat |
| **Release-Takt** | Ein Update pro Monat | Fortlaufend |

## Welche Edition sollten Sie nutzen?

| Wenn Sie … sind | Nutzen Sie | Warum |
|---|---|---|
| Studierende, Hobbyisten oder unabhängig Lernende | **Open Source** | Wirklich kostenlos — und das bleibt so |
| Akademisch Forschende | **Open Source** | Kostenlos für akademische Nutzung — Hochschulen mit Bedarf an verwalteten Plätzen: siehe Hochschulpaket unten |

| Beruflich damit Geld verdienend | **Enterprise** | In der Praxis günstiger — und die einzige Edition mit täglicher Weiterentwicklung |

> **Ehrlich gesagt:** Der offene Build ist echte Arbeit, kein beschnittenes Demo — aber er läuft auf kostenlosen öffentlichen Feeds, **Ihren** API-Schlüsseln und **Ihrem** LLM-Schlüssel, und jeder KI-Aufruf wird Ihnen pro Token in Rechnung gestellt, ohne Obergrenze. Community-Issues werden nach bestem Bemühen und ohne Reaktionszusage bearbeitet. Wenn Sie mit dem Terminal Ihr Geld verdienen, ist Enterprise der günstigere und sicherere Platz.

## Open-Source-Edition installieren

Fertige Installationsprogramme für **Windows x64**, **Linux x64** (`.run` / `.deb` / `.rpm`) und **macOS (Apple Silicon)** finden Sie auf der [Releases-Seite](https://github.com/Fincept-Corporation/FinceptTerminal/releases/latest).

**Aus dem Quellcode bauen** — Linux/macOS: `git clone … && ./setup.sh`. Windows, manuelle Builds, die fixierte Toolchain (**CMake 3.27.7 · Ninja 1.11.1 · Qt 6.8.3 · Python 3.11.9**) und Fehlerbehebung stehen in **[docs/GETTING_STARTED.md](../GETTING_STARTED.md)**. Die Versionen sind fixiert — neuere oder ältere werden nicht unterstützt.

> Sie suchen den Enterprise-Build? Er hat eigene signierte Installer für Windows, macOS und Linux hinter einem Enterprise-Login — [hier erhältlich](https://fincept.in/enterprise).
